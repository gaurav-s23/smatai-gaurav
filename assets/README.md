## 📝 Usage

To add new screenshots:
1. Take screenshots of the application
2. Place them in the appropriate subdirectory
3. Update this README with the new file names
4. Reference screenshots in the main README.md using relative paths

## 🎨 Screenshot Guidelines

- Use high-resolution images (1920x1080 or higher)
- Maintain consistent styling and theme
- Include meaningful data in screenshots
- Ensure mobile screenshots show responsive design
- Use dark theme to match application design
